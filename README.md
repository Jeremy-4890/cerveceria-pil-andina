# cerveceria-pil-andina
# 🍺 Sistema de Gestión de Inventario - Cervecería Pil Andina

Sistema completo de gestión de inventario para la Cervecería Pil Andina, desarrollado con Flask y MySQL.

##  Descripción del Proyecto

El sistema soluciona los siguientes problemas:
- ❌ Control de inventario descentralizado en Excel
- ❌ Falta de trazabilidad de lotes de producción
- ❌ Distribuidores sin visibilidad de stock en tiempo real
- ❌ No hay cálculo de rotación de inventario
- ❌ No existen alertas de productos próximos a vencer

##  Tecnologías Utilizadas

- **Backend:** Python 3.11 + Flask
- **Base de Datos:** MySQL (XAMPP)
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Gráficos:** Plotly, Chart.js
- **Seguridad:** Werkzeug (hash de contraseñas)

##  Requisitos Previos

- XAMPP (Apache + MySQL)
- Python 3.11 o superior
